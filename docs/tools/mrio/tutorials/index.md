
# Tutorials

This section provides step-by-step tutorials for working with MRIO.

Two tutorials are available:

- **Website Tutorial:** Explains how to use the MRIO web application to upload, inspect, modify, validate, and export CityJSON and CityJSONSeq datasets.
- **UI Tutorial:** Provides step-by-step instructions for using the MRIO Terminal User Interface (TUI) to open, inspect, modify, validate, and save building datasets.
