
# Tutorials

- **Web-based MRIO:** Explains how to use the MRIO web application to upload, inspect, modify, validate, and export CityJSON and CityJSONSeq datasets.
- **CLI-based MRIO:** Provides step-by-step instructions for using the MRIO Command Line Interface (CLI) to open, inspect, modify, validate, and save building datasets.
