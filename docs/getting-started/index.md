# Getting started

This page explains how the site is organized and where to begin, depending on your
role. For an introduction to the project itself, see
[About MultiRoofs](../about-multiroofs/index.md).

## What is on this site

The site has two parts:

- **Project background** covers the concepts behind rooftop activation: urban
  challenges, rooftop functions, buildings and districts, property owners,
  incentives, and digital twins. These pages also form the basis of the MultiRoofs
  training for local authorities.
- **Tools** documents each tool developed or used in the project.

## How tool pages are organized

Each tool section contains some or all of the following page types. Pick the one
that matches what you need right now.

| Page type | Use it when you want to... |
|---|---|
| **Tutorials** | Learn the tool by completing a guided first task. |
| **How-to guides** | Solve a specific problem you already have. |
| **Background** | Understand how the tool works and why it was designed that way. |
| **Reference** | Look up functions, parameters, or endpoints. |

## Working with owner data

Some analyses link property owner information to specific buildings. When an owner
is a natural person, this information can be personal data under the EU General
Data Protection Regulation (GDPR). Before combining ownership records with building
data, check with your organization's data protection officer which data you may use
and how it must be stored.
