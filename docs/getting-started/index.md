# Getting started

Project-wide setup and how the tools fit together.

## How the tools fit together

1. **geokit** computes distances and polygon areas in the data pipelines.
2. Results are stored in the **Inventory API**.
3. **mapview** shows building footprints on a web map.
4. **NumPy** is used for array maths throughout.

Pick a tool from the sidebar to learn more.
